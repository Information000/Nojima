# 店舗ごとの公開データ

成田店（`narita`）以外の店舗の内容は、このフォルダに **店舗IDのフォルダ** を作って置きます。
置いた店舗にだけ反映され、ほかの店舗は変わりません。

```
stores/
  <店舗ID>/
    store.json        … ホームのマップ（ホームの ⚙ → JSONを書き出し）
    area-home.json    … 家電エリア（エリアページの ✏️ 編集 → 書き出し）
    area-av.json      … 季節・AVエリア
    area-info.json    … 情報エリア
    area-comm.json    … 通信エリア
    fridge.json など  … 商品ページ（🔐 在庫管理 → ⋯ →「この店舗の公開用データを書き出す」）
```

- 店舗IDは、商品ページの在庫管理で書き出したときの案内（`stores/<店舗ID>/`）に表示されます。
- 店舗IDは店舗名から決まるため、別の端末で同じ店舗名を選ぶと同じデータを使います。
- 成田店の内容を変えるときは、これまでどおり各ページの HTML（`fridge/index.html` など）を差し替えます。
